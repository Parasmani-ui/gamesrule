## 🔑 KEY FORMULAS & CONCEPTS

### Fruit Beer Game
```
Bullwhip Ratio = Variance(Orders) / Variance(Demand)
Total Cost = Holding Cost × Inventory + Stockout Cost × Backorder
```

### TOC Simulation
```
Throughput = Min(All Process Capacities)
Hour lost at bottleneck = Hour lost for entire system
```

### Defect Detectives
```
Control Limits: UCL = μ + 3σ, LCL = μ - 3σ
Total Quality Cost = Prevention + Appraisal + Failure Costs
```

### Customer in Store
```
Stock(t) = Stock(t-1) + Inflow(t) - Outflow(t)
Peak Stock ≠ Peak Flow (occurs at crossover)
```

### Demand Forecast
```
MAD = Σ|Actual - Forecast| / n
MAPE = (Σ|Error / Actual|) / n × 100%
Exponential Smoothing: F(t+1) = α×A(t) + (1-α)×F(t)
```
