**From Fruit Beer Game Section:**

```
THEORETICAL FOUNDATION
- Core Concept: Bullwhip Effect (Forrester Effect)
- Formula: Bullwhip Ratio = σ(Orders) / σ(Demand)
- Key Principle: Demand amplification increases exponentially 
  with each tier upstream

KEY LEARNINGS
1. Operational: Order only what you need, not what you fear
2. Strategic: Information sharing eliminates bullwhip effect
3. Behavioral: Fear of stockouts leads to overordering

REAL-WORLD APPLICATIONS
- Walmart's vendor-managed inventory system
- Toyota's just-in-time (JIT) production
- Amazon's demand forecasting algorithms
```

**From TOC Simulation Section:**
```
THE FIVE FOCUSING STEPS
1. IDENTIFY the system's constraint (bottleneck)
2. EXPLOIT the constraint (maximize its output)
3. SUBORDINATE all other processes to the constraint
4. ELEVATE the constraint (add capacity)
5. REPEAT - when constraint shifts, start over

KEY INSIGHTS
- Hour Lost at Bottleneck = Hour Lost for Entire System
- Hour Saved at Non-Bottleneck = Mirage
- Increasing Efficiency ≠ Increasing Throughput
```
